# 情绪日记与自我关怀

低门槛情绪记录与自助调节工具：

- 记录情绪与强度
- 标注触发因素并生成洞察
- 推荐冥想 / 音乐 / 运动方案

数据仅保存在浏览器本地（localStorage）。

## 在线访问

- 站点：https://emotion-diary-brown-rho.vercel.app/
- 仓库：https://github.com/TR277/emotion-diary

## 本地预览

```bash
npm run dev
```

## Vercel 部署

```bash
npx vercel login
npx vercel --prod
```
